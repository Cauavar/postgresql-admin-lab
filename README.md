# PostgreSQL Admin Lab

Hands-on PostgreSQL project focused on database administration, security, maintenance, performance analysis, backup and recovery, and automation.

## About the Project

This repository documents my practical learning journey with PostgreSQL through hands-on exercises and administration tasks.

The goal is to build a strong foundation in database administration while applying PostgreSQL concepts in practical scenarios.

## Topics Covered

- PostgreSQL fundamentals
- Database and schema management
- SQL and data manipulation
- Query analysis
- Indexes and query optimization
- Users, roles, and permissions
- Principle of least privilege
- Backup and recovery
- VACUUM and ANALYZE
- Autovacuum
- EXPLAIN and EXPLAIN ANALYZE
- Windows batch automation
- Linux shell scripts
- Task scheduling
- Logging
